# SALON 59 – Premium Luxury Salon Website

A modern, high-conversion single-page luxury salon website built for **SALON 59** located in Uttam Nagar, New Delhi.

Designed under the **LUXURY FEMININE – NUDE PINK & ROSE GOLD** aesthetic with editorial beauty typography, authentic brand assets, responsive layout, interactive lightbox gallery, and direct WhatsApp appointment booking.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
# The website will be available at http://localhost:3000
```

---

## 📦 Production Build & Deployment

```bash
# Generate production bundle
npm run build

# Preview production build locally
npm run preview
```

### Deploying to Vercel
1. Push this repository to GitHub or run `vercel` in the project root.
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. The included `vercel.json` ensures instant clean routing for all assets.
